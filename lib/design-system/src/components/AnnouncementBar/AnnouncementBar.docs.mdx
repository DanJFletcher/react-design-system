## Placement and persistence

- Place the announcement before the site `Header` in DOM order so visitors encounter the notice before navigating the site.
- `sticky` uses `position: sticky` at the top of its containing scroll context. It remains in normal document flow and is not portaled or fixed to the viewport.
- Visibility is uncontrolled by default and starts visible. Use `visible` with `onVisibleChange` for controlled state, or `defaultVisible` for an initially hidden uncontrolled bar.
- Dismissal calls `onVisibleChange(false)`. The component does not persist dismissal; the host application owns any persistence policy.
- `children` is required visible message text. `title`, `icon`, and `action` are optional slots; provide a text label for icon-only actions supplied by the host.
- The region and dismiss button have configurable accessible names through `announcementLabel` and `dismissLabel`. The icon slot is decorative for assistive technology.
- Tones follow Callout: `info`, `success`, `warning`, `error`, and `neutral`. The component uses design tokens and supports forced-colors mode.

## Read-only display

Use `mode="display"` (the default) with a numeric `value`. Display mode accepts fractional ratings for review summaries, uses a named image for assistive technology, and can optionally show the numeric score.

<Canvas of={RatingStories.ReadOnlyDisplay} />

## Selectable form input

Use `mode="input"` with a visible `label`. It renders a native radio group. By default there is one option for each whole-step value; set `step={0.5}` to offer half-step choices. Arrow keys move between options, Tab enters or leaves the group, and the selected value is submitted using `name`.

Choose `symbol="star"`, `"heart"`, or `"thumbs"`; stars are the default. Accessible names describe the score and symbol (for example, “3.5 out of 5 hearts”). `getRatingLabel` customizes or localizes that wording. `value` with `onValueChange` provides controlled state; `defaultValue` initializes uncontrolled state. Use `required`, `disabled`, `description`, `error`, and `invalid` for form states. `formatValue` customizes the optional visible numeric value.

```tsx
<Rating
  mode="input"
  label="Service rating"
  name="serviceRating"
  max={5}
  step={0.5}
  symbol="heart"
  defaultValue={3.5}
  required
  onValueChange={(value) => setRating(value)}
/>
```

## Scale, size, and themes

`max` must be an integer from 1 to 10 and defaults to `5`. Input mode uses whole-star values by default; `step={0.5}` adds half-star options while preserving native radio keyboard behavior. Read-only mode supports fractional values. Fractional fills clip a full-size symbol, keeping its filled and outlined portions aligned rather than shrinking the filled drawing. This applies to stars, hearts, and thumbs in both modes. `size` accepts `sm`, `md`, or `lg`.

## Interactive playground

<Canvas of={AccordionStories.Playground} />

Use the controls to choose a variant, size, shape, heading level, and whether multiple panels may remain open. Each title is a native button; Enter or Space toggles it and normal Tab order is retained.

`items` requires a unique `id` per item and accepts `title`, `content`, and optional `disabled`. The default `multiple={false}` closes another open panel when a new one opens. Use `multiple` to let each panel toggle independently.

## Expand and collapse motion

<Canvas of={AccordionStories.ExpandCollapseMotion} />

Set `panelMotion="expand"` to animate panel size and opacity with the shared standard duration and easing tokens. The default `none` keeps panel content opening and closing immediately; the chevron retains its existing rotation transition. System or Storybook reduced-motion settings make the panel change instantly.

## Theme coverage

<Canvas of={AccordionStories.ThemeCoverage} />

The component uses semantic text, surface, border, focus, spacing, and radius tokens, so variants follow ACME, Atom, Luna, Orchid, and custom themes. Pass `className` or typed `style` for scoped customization.

## State and accessibility

`defaultOpenItems` initializes uncontrolled state. `openItems` with `onOpenItemsChange` provides controlled state. In controlled mode, the parent updates `openItems` in response to the callback. Disabled items cannot be toggled. Panels remain mounted and use `hidden` while closed.

Each heading contains a native button with `aria-expanded` and `aria-controls`; its panel uses `role="region"` and `aria-labelledby`. Set a useful `label` when the accordion should be named as a group. Choose `headingLevel` to match the surrounding page hierarchy.

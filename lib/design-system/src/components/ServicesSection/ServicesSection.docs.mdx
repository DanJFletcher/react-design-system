## Behavior and semantics

- `heading` is optional. When provided, it labels the section and service card headings use the next heading level; without a heading, provide `aria-label` to name the section. If no label is provided, the component uses “Services”.
- `items` is a list of service records with stable `id` values, titles, optional descriptions, decorative icons, or image content.
- A service can provide a `link` with an optional custom label, or an `action` containing consumer-owned content such as a Button. The component does not handle bookings or submissions.
- `columns` sets the desktop column count from 1–4. Three and four columns reduce to two at tablet widths, and all layouts stack on narrow screens.
- `cardVariant`, `cardSize`, `cardShape`, `cardAlignment`, `mediaAspectRatio`, and `mediaFit` configure the cards using the shared Card component.
- `variant` accepts `plain`, `surface`, or `accent`. The `services.*` hooks customize section surface, text, supporting text, border, links, radius, padding, and spacing.

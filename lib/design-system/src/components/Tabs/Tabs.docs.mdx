## State and keyboard access

`defaultValue` initializes uncontrolled state. Use `value` and `onValueChange` for controlled state; the parent must update `value` when it accepts a change. If the selected item becomes missing or disabled, the first enabled item is shown. An empty or fully disabled list has no selected panel.

The named `role="tablist"` contains native buttons with `role="tab"`, `aria-selected`, `aria-controls`, and roving `tabIndex`. Panels use `role="tabpanel"` and `aria-labelledby`; inactive panels remain mounted but hidden. The selected panel is focusable.

Horizontal tab lists use Left/Right Arrow and vertical tab lists use Up/Down Arrow. Horizontal arrow direction follows right-to-left text. Home/End focus the first/last enabled tab. In automatic mode, moving focus also selects the tab; in manual mode, Enter, Space, or pointer activation selects the focused tab.

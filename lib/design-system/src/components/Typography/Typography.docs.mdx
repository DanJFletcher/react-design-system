## Text

<Canvas of={TypographyStories.TextScale} />

`Text` renders a paragraph by default; use `as="span"` or `as="div"` when the surrounding content requires different HTML semantics. `size` accepts the shared `xs` through `5xl` scale, `weight` accepts `regular`, `medium`, or `semibold`, and `tone` accepts `primary` or `muted`.

## Heading

<Canvas of={TypographyStories.HeadingLevels} />

`Heading` renders the native `h1` through `h6` selected by `level`. Visual `size` is independent of the semantic heading level; it defaults to a descending scale from `5xl` for `h1` to `lg` for `h6`. Use the level that matches the document outline, even when choosing a different visual size.

## Weight, tone, and themes

<Canvas of={TypographyStories.WeightsAndTones} />
<Canvas of={TypographyStories.ThemeCoverage} />
<Canvas of={TypographyStories.NestedThemeBoundary} />
<Canvas of={TypographyStories.ResponsiveWrapping} />

Both components use the active theme's font-family, font-size, font-weight, line-height, and semantic text-color tokens. They work in ACME, Atom, Luna, Orchid, and custom themes without theme-specific rendering. Native HTML attributes, children, refs, `className`, and typed `DesignSystemStyle` are forwarded.

In Atom, semantic H1 and H2 headings have two solid marker highlights with matching uneven clipped edges. Cyan is offset down and to the right; electric yellow sits behind the cyan, offset up and to the left. Dark ink sits above both layers to keep the text readable. This follows the heading's HTML level, not its visual `size`, and also applies to native `h1`/`h2` elements. H3–H6 and headings within another nested theme keep their usual appearance. High-contrast mode removes both decorative highlights.

## Accessibility

Choose heading levels according to page structure rather than visual size. `Text` adds no implicit role; its selected element retains native browser semantics. Long headings wrap instead of clipping, and forced-colors mode uses the system text color.

## Text

<Canvas of={TypographyStories.Playground} />
<Canvas of={TypographyStories.TextScale} />
<Canvas of={TypographyStories.TextElements} />

`Text` renders a paragraph by default; use `as="span"` or `as="div"` when the surrounding content requires different HTML semantics. Its `variant` selects a semantic role: `body` (default), `body-small`, `lead`, `label`, `caption`, `eyebrow`, or `display`. The existing `size` and `weight` props remain available as explicit overrides. `tone` accepts `primary` or `muted`.

Set `measure` to `narrow`, `content`, or `wide` to limit a block of text to a themeable reading width; `none` leaves the width to its parent.

## Heading

<Canvas of={TypographyStories.HeadingLevels} />
<Canvas of={TypographyStories.SemanticRolesAndMeasure} />

`Heading` renders the native `h1` through `h6` selected by `level`; each level uses its own themeable size, weight, line-height, and letter-spacing tokens. `variant="display"` opts into the display role. Visual `size` remains independent of the semantic heading level, and `weight` can override a role's default. Use the level that matches the document outline.

## Weight, tone, and themes

<Canvas of={TypographyStories.ResponsiveWrapping} />

Both components use the active theme's font families, semantic font roles, letter spacing, reading measures, and text-color tokens. The `xs` through `5xl` primitive size scale remains available for one-off overrides. They work in ACME, Atom, Luna, Orchid, Sublime, and custom themes without theme-specific rendering. Native HTML attributes, children, refs, `className`, and typed `DesignSystemStyle` are forwarded.

In Atom, semantic H1 and H2 headings have two solid marker highlights with matching uneven clipped edges. Cyan is offset down and to the right; electric yellow sits behind it, offset up and to the left, with dark ink above both layers. H3 uses hot pink in front and cyan behind it; H4 and H5 use black in front and hot pink behind it; H6 uses purple in front and black behind it. H3–H6 use light text for readability. The treatment follows the heading's HTML level, not its visual `size`, and applies to native heading tags as well as `Heading`. Headings within another nested theme keep that theme's usual appearance. High-contrast mode removes the decorative highlights.

`Heading` and `Text` remain flat in Atom; the theme's hard-offset shadows are reserved for surfaces and controls.

## Accessibility

Choose heading levels according to page structure rather than visual size. `Text` adds no implicit role; its selected element retains native browser semantics. Long headings wrap instead of clipping, and forced-colors mode uses the system text color.

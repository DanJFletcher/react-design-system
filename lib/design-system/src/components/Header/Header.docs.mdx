## Responsive playground

<Canvas of={HeaderStories.Playground} />

Use the Storybook controls to edit navigation links, the accessible logo link, the three height sizes, sticky behavior, and the bottom border. By default, Header uses the design-system `Menu` in navigation mode: it opens as a compact menu on narrow screens and lays out inline with the CTA at desktop widths.

## Height sizes

<Canvas of={HeaderStories.HeightExamples} />

`size` accepts `sm`, `md`, or `lg`, with minimum header heights of 48px, 64px, and 80px. The expanded mobile menu adds the height its content needs.

## Sticky and border options

<Canvas of={HeaderStories.StickyWithoutBorder} />

`sticky` is off by default. When enabled, the header sticks to the top of its scrolling container. `borderBottom` is on by default and can be disabled independently.

## Theme coverage

<Canvas of={HeaderStories.ThemeCoverage} />

The component uses semantic surface, text, border, focus, and spacing tokens, so the same props work in ACME, Atom, Luna, Orchid, and custom themes.

## Accessibility and API

`logo` accepts any React node; `logoHref` and `logoLabel` configure its home link. Provide a useful `logoLabel` when replacing the default logo. `navItems` is an array of native anchor props plus a required `label` and `href`; set `current` for the current page and use `icon` for optional decorative icon content. `cta` accepts a React node so it can contain the design-system `Button` or another custom action. By default, the same CTA slot appears in the mobile navigation panel and inline at desktop widths.

The default mobile navigation uses `Menu` with `mode="navigation"`, so its panel is a named native navigation landmark with ordinary links rather than an ARIA application menu. Tab follows normal document order. Escape closes the panel and restores focus to its trigger; choosing a link closes it.

Set `renderMobileNavigation` to replace the default mobile `Menu`. The render function receives an `id`, the navigation label, `navItems` with close-on-activation handlers, and the controlled `open` state with `onOpenChange`. The replacement owns its trigger, landmark, and focus behavior. Header keeps its CTA as a separate slot below a custom mobile navigation and inline at desktop widths.

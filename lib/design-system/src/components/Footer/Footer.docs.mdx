`brand` and `description` are optional. Use `logoHref` and `logoLabel` to make the brand a named home link. `linkGroups` creates a labeled navigation with headings; `socialLinks` and `legalLinks` create separate labeled navigation regions. Links accept native anchor attributes, including `target`, `rel`, and event handlers.

## Theme coverage

<Canvas of={FooterStories.ThemeCoverage} />

The footer uses semantic text, surface, border, focus, and spacing tokens, so the same props work in ACME, Atom, Luna, Orchid, and custom themes. This example uses Luna; the plain playground follows Storybook's active theme. Pass `className` or typed `style` for scoped customization. The `children` slot and `bottomContent` accept consumer-owned content.

## Semantics

The component renders a native `footer`; each non-empty link collection uses a native `nav` with its own accessible name. Provide visible text for links, or an `aria-label` when a link uses only an icon. Group titles are headings; choose `headingLevel` to match the page hierarchy. Footer navigation and destinations are stateless and remain under consumer control.

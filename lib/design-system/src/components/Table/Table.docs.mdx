# Table

A semantic, theme-aware table for structured data. Configure columns with direct property access or accessors, provide custom cell renderers, and opt into client-side or manually controlled sorting and row selection.

## Interactive playground

<Canvas of={Stories.Playground} />

Use the controls to adjust density, borders, stripes, hover behavior, sorting mode, selection mode, and sticky headers.

## Column definitions

Each column needs a stable `id` and a header. `accessor` can name a row property or return a value. `cell` can format or replace the displayed value, while `footer` can provide a static summary or calculate one from the displayed rows.

```tsx
const columns: TableColumn<Business>[] = [
  {
    id: "name",
    header: "Business",
    accessor: "name",
    sortable: true,
  },
  {
    id: "rating",
    header: "Rating",
    accessor: (business) => business.rating,
    align: "end",
    cell: ({ value }) => `${Number(value).toFixed(1)} / 5`,
  },
];
```

Set `hidden` to omit a column, or provide width constraints, alignment, header and cell classes, a custom comparator, and sort values per column.

## Sorting and selection

Sortable columns support ascending, descending, and unsorted states. Client mode sorts rows locally; manual mode only reports sort changes so a consumer can fetch or reorder data itself. Use `sort` with `onSortChange` for controlled state, or `defaultSort` for an uncontrolled initial sort.

Set `selectionMode` to `single` or `multiple` to enable row selection. Multiple selection includes a select-all checkbox for selectable visible rows. Supply `getRowKey` for stable row identity and `selectedRowKeys` with `onSelectionChange` to control selection.

## Responsive and accessible behavior

The table keeps native table semantics and can scroll horizontally when columns need more space. A caption or `aria-label` names the table. Use `captionHidden` to retain a caption for assistive technology without showing it visually. Loading status, empty content, density, sticky headers, and selection labels are configurable.

## Themes and style hooks

The component inherits the active theme and accepts `DesignSystemStyle` overrides:

- `table.surface`, `table.text`, and `table.border`
- `table.header-surface`, `table.header-text`, `table.striped-surface`
- `table.row-hover`, `table.row-selected`, and `table.muted`
- `table.radius`, `table.padding`, `table.compact-padding`, and `table.gap`

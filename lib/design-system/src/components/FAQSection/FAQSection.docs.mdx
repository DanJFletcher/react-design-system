Questions render as native buttons inside headings one level below the section heading. Enter and Space use normal button behavior; Tab order is the Accordion's native order. `defaultOpenItems` initializes uncontrolled state; `openItems` and `onOpenItemsChange` provide controlled state. `multiple` allows more than one answer to stay open. Disabled questions cannot be opened. An empty `items` array renders nothing.

The visible section heading names the section by default. Native `aria-label` and `aria-labelledby` can override that name. IDs must be unique and non-empty; the heading and each question must contain visible text, and every item must have an answer. Invalid data or heading levels outside 1–5 throw.

The component reuses Accordion's semantic theme tokens and public appearance props. It needs no FAQ-specific tokens or theme branches and follows ACME, Atom, Luna, Orchid, custom themes, scoped styles, and nested theme boundaries.

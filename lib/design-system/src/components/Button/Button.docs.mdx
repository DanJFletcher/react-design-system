## Theme boundaries and customization

<Canvas of={ButtonStories.NestedThemes} />
<Canvas of={ButtonStories.CustomThemeAndScopedOverride} />

Semantic variables are direct values, so overriding a resting action color does not alter its hover or pressed states. Register no new hook without documenting its purpose and adding it to `src/tokens/component-hooks.json`; every hook resets at nested theme boundaries.

## API limits

`Button` forwards native button props, refs, accessible naming attributes, `className`, and form attributes. Icons may be children; hide decorative icons from assistive technology. The component deliberately does not provide `href`, `asChild`, toggle semantics, groups, or an icon-only convenience API.

Visual overrides are limited to the generated `DesignSystemStyle` custom-property type. Public hook names and fallback tokens are documented in the **Foundations / Customization** page.

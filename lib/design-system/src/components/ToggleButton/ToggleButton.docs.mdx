# ToggleButton

Use a toggle button for an action with a persistent on/off state, such as saving a bookmark or enabling a text-formatting option. It builds on the standard Button variants and uses shared selected-state background, foreground, and boundary tokens while pressed.

<Canvas of={ToggleButtonStories.Playground} />

## Controlled and uncontrolled state

Set `defaultPressed` to let the button manage its own state, or provide `pressed` with `onPressedChange` to control it from a parent. The component exposes its state with `aria-pressed`.

<Canvas of={ToggleButtonStories.Controlled} />

## Toolbars and themes

Independent toggle buttons can be arranged with `ButtonGroup`. The group provides layout and an accessible name; each ToggleButton manages its own pressed state.

Selected styling comes from `color.action.selected.*` and can be overridden per control with `toggle.selected.*` style hooks. Disabled toggles continue to use the shared disabled action tokens.

```tsx
<ToggleButton
  pressed={isSaved}
  onPressedChange={setIsSaved}
  aria-label="Save bookmark"
  icon={<Icon name="star" />}
  iconOnly
  variant="ghost"
/>
```

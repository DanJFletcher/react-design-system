## Ratings and narrow layouts

Testimonials use the shared `Rating` display mode for accessible star summaries. Ratings are announced with localized text and the star glyphs are decorative. The grid collapses to one column on narrow screens.

See the [Rating component](iframe.html?id=components-rating--docs&viewMode=docs) to display fractional scores or collect a selectable rating in a form.

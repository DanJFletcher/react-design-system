## Behavior

- `label` is required, visible, and names the progressbar.
- Provide `value` for determinate progress; omit it for indeterminate progress. `max` defaults to `100` and must be greater than zero.
- Values outside `[0, max]` are clamped; non-finite values and invalid maxima throw a `RangeError`.
- Determinate progress exposes `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`. Indeterminate progress omits `aria-valuenow`.
- `valueText` overrides the displayed value and is exposed as `aria-valuetext`. `showValue={false}` hides the visual value but keeps the accessible numeric value.
- `aria-describedby` is forwarded to the progressbar. Progress updates do not create a live region.
- `progress.*` hooks customize the track, indicator, label/value text, height, radius, and spacing. The component supports nested themes, reduced motion, and forced colors.

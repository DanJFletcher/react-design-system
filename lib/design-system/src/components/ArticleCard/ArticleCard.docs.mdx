## Semantics and behavior

- The card is a native `<article>` named by its heading. The heading and optional “Read article” action link to `href`; categories and author links remain independent.
- `publishedAt` takes a machine-readable `dateTime` value and a visible localized label. The component does not format dates or calculate reading time.
- `image` accepts native image attributes. Provide meaningful `alt` text for informative images and `alt=""` for decorative imagery. It defaults to lazy loading and async decoding.
- `layout`, `mediaPosition`, `mediaAspectRatio`, and `mediaFit` follow the existing Card API. Links remain keyboard accessible, visibly identifiable, and visible in forced-colors mode.
- The component presents supplied content; it does not fetch posts, resolve routes, or manage publishing.

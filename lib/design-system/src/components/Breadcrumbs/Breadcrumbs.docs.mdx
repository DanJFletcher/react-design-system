## API and behavior

```tsx
<Breadcrumbs
  aria-label="Service breadcrumb"
  collapseAt="56rem"
  items={[
    { label: "Home", href: "/" },
    { label: "Services", href: "/services" },
    { label: "Repairs", current: true },
  ]}
/>
```

`Breadcrumbs` renders a named native navigation landmark with an ordered list. Provide parent items with visible `label` text and native-link `href` destinations, then mark the final item with `current: true`. The current page is rendered as text with `aria-current="page"` rather than a link. The default landmark name is “Breadcrumb”; customize it with `aria-label` when a page has more than one navigation landmark.

The optional `collapseAt` prop sets the viewport width at or below which intermediate links collapse, using a CSS width value such as `"56rem"` or `"640px"`. When omitted, the existing default of `40rem` is used. The disclosure button can expand or hide the intermediate levels at either breakpoint.

The component does not inspect the URL, generate destinations, or own routing. Native links retain browser navigation and keyboard behavior. Long labels wrap on narrow screens, and colors, spacing, corner radius, and focus styling inherit built-in, custom, and nested theme tokens.

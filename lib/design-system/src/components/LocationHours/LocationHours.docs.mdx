## Playground

<Canvas of={LocationHoursStories.Playground} />

`LocationHours` reuses the library's contact details and accepts optional map content from the consumer. Provide an embed or another map view as `map`; the component does not require a map provider or API key. `layout` selects a split or stacked arrangement, and `mapPosition` places the map before or after the details.

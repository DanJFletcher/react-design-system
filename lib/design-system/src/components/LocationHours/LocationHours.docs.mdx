## Playground

<Canvas of={LocationHoursStories.Playground} />

`LocationHours` reuses the library's contact details and accepts optional map content from the consumer. Provide an embed or another map view as `map`; the component does not require a map provider or API key. `layout` selects a split or stacked arrangement, and `mapPosition` places the map before or after the details.

Set `openStatus` to display a live open/closed message with the next closing or opening time. Provide the location's IANA `timeZone` (for example, `America/Toronto`) and add `dayOfWeek` (`0` = Sunday through `6` = Saturday) plus structured `intervals` (`opensAt` / `closesAt` in 24-hour `HH:mm`) to each of the seven `hours` entries. Use an empty `intervals` array for a closed day. The displayed text in `hours` remains customizable. Status updates every minute and handles overnight hours.

Pass `specialHours` for one-off holiday schedules, early closings, or temporary closures. Each entry needs a unique `id`, a local calendar `date` in `YYYY-MM-DD`, display text in `hours`, and structured `intervals`; an empty interval list means closed. An exception replaces the weekly schedule on its date, is shown in a separate “Special hours” list, and is included when calculating the live status. Past exceptions are hidden automatically. Set `timeZone` to the business location's IANA timezone so dated exceptions are filtered against the local calendar date; `openStatus.timeZone` is used automatically when live status is enabled.

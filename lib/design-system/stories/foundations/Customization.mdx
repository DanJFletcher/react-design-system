<Title>Customization</Title>

Semantic variables are the stable styling API. Override them directly on any scoped element; semantic variables resolve to concrete values during generation.

```css
.campaign {
  --ds-color-action-primary-bg: #343A40;
  --ds-color-action-primary-hover: #252A2F;
}
```

Component hooks are optional component-specific overrides. They remain unset by the component and use local fallbacks. A hook set outside a nested theme is reset at that boundary; a hook set on the inner boundary takes effect there.

`ThemeScope` is an optional wrapper for a theme name and a typed hook-only `style` object. It does not mutate `document` or define global theme state.

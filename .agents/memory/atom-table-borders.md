---
name: Atom table borders
description: Border color treatment for tables in the Atom theme.
---

Atom-themed tables, including tables inside long-form articles, use the cyan accent for their borders and grid lines.

**Why:** The user explicitly requested cyan borders for tables in the Atom theme.

**How to apply:** Apply this to both the standalone table component and native article tables within Atom; other themes should continue using their own table border tokens.

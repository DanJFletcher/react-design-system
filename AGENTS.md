# Repository agent instructions

- Before proposing an approach, planning a task, or starting any work that may affect `lib/design-system/`, read `lib/design-system/CONTRIBUTING.md` first.
- This applies to code, documentation, tokens, themes, Storybook stories, tests, package exports, and build configuration.
- After the contribution guide, read `lib/design-system/AGENTS.md` and the relevant component or design-system documentation before making changes.
